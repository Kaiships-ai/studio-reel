# Content types

A content type is the shape of a reel's script: which beats come in which order, how long each one runs, how it
hooks and how it ends. It works with any style. The style decides how the reel looks; the content type decides what
the viewer hears and when. `/studio` proposes one from the buyer's idea, and `/make-reel --type <name>` follows it.

| Type | Status | Pick it when the idea is | Example idea |
|---|---|---|---|
| [listicle](listicle.md) | proven | a set of things worth knowing: tools, tips, places, mistakes | "5 apps I use daily" |
| [education](education.md) | proven | how to use ONE thing, taught as a named process of a few steps | "how I plan a week with one notebook" |
| [why](why.md) | new | a question or a claim about cause: why something happens, fails or works | "why AI agents fail" |
| [explanation](explanation.md) | improving | how something works, told through one picture everyone already knows | "what an API is" |

When an idea fits two types, pick the one with fewer beats; a reel carries one idea. A list of steps toward one
result is **education**, not a listicle. "Why" is about causes; "explanation" is about mechanism.

## What every type shares

- **Length** 30–60 s, 70–160 spoken words. Under 45 s is the safe default for a first reel.
- **The hook is line 1** and the first 3 s of picture: something is already moving on frame 0, and the viewer knows
  who it is for and what they get before 2 s.
- **Every number, name, price or claim** comes from the buyer or a source you can name. Invent visuals, never facts.
- **The CTA is the last line**: one action and exactly what they get ("Comment MENU and I'll send you the full list"),
  said in one breath, no commas around the keyword. Use the brand's keyword from `workspace/brand.md` when it has one.
- **Picture follows the words**: each beat's key visual lands on its spoken word, and anything the viewer must read
  is on screen long enough to read it (at least 0.5 s, large enough to read on a phone).

## Each file has the same sections

When to use · Beats (with timings at 30, 45 and 60 s) · Hook patterns · CTA rule · Styles that suit it · A worked
outline. To add a type, copy one file, keep the sections and mark its status `new` until a finished reel proves it.
