# Stick-man kit reference

The make-reel-stick-man skill holds the process. These files hold the kit's full vocabulary:
- VERBS.md: beat keys, actor verbs, poses, faces and effects. Verbs drive background characters and older auto-mode reels; a lead is acted with motion v2 keys.
- SETS.md: the `lib/sets` places, props and cast specs. The allout sets are in `../allout/README.md`.
- GLB.md: building sets from Blender `.glb` pieces.
