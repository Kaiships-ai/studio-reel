# Pilot A (worked example of the standard process)

20.5 s, one narrator, set `canyon-edge`, style `kaiships`.
`reel.js` (cameras, overlays, blocking + polish keys, sound beats), `storyboard.json` (see / still / act / props per line),
`script.json` + `words.json` (voice text and alignment), `music.json` (the music arc), `LEDGER.md` (what each stage made
and how it was proven). To play it: copy into `films/pilot-a/` (script.json and words.json under `vo/`, music.json under
`audio/`), record the voice with `tools/voice.py`, then follow the skill.
