# Example scripts

Three ready scripts that show off what the kit can animate. Each file is a `vo/script.json` plus two extra notes:
`concept` (the world and the camera idea) and `shows_off` (the techniques it exercises). Make one with:

> /make-reel examples/02-api-explained.json

or in plain words: "Make a reel from examples/02-api-explained.json". Claude copies the script to `vo/script.json`
word for word and uses the concept as a starting point (it may invent a better one).

| file | format | length | best for seeing |
|---|---|---|---|
| `01-morning-routine.json` | 4-tip listicle | ~25 s | one room, lots of action, squash and stretch |
| `02-api-explained.json` | metaphor explainer | ~25 s | two characters, camera that follows a prop |
| `03-tools-listicle.json` | tool listicle (fill in your tools) | ~25 s | the format behind a 92k-view reel |
