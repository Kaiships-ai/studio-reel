# How we make Ten Million Views

This folder is a studio for short vertical episodes: your characters, your story, several linked
episodes, each ending in a vote ("Comment A or B") that the next episode picks up.

- Setup: follow `START.md` (the buyer pastes one prompt that says so). Tools install inside this
  folder with pixi: `pixi run studio install`, then `pixi run studio doctor`.
- Render preview quality (720x1280) unless the user says "final".
- Never print or commit keys. A Gemini key, if the user gives one, goes in `.env` here only.
- Support: Discord (Buyer role) or kaiships.ai@gmail.com.
